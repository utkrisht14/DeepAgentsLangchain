# Professional Email Skill

When writing a professional email:

1. Start with a suitable greeting.
2. Clearly state the purpose in the first paragraph.
3. Keep the message concise.
4. Include any requested action or next step.
5. End politely.
6. Follow the communication preferences from AGENTS.md.
